    UT03 · Manejo de listas en Kotlin¶

    Módulo: Programación Multimedia y Dispositivos Móviles (PMDM) · Curso: 2.º DAM

    Objetivos de aprendizaje¶

    Al finalizar este apartado podrás crear y recorrer listas, distinguir colecciones de solo lectura y mutables, manipular objetos, aplicar operaciones de filtrado y representar colecciones en una interfaz Android desarrollada con Jetpack Compose.

    1. ¿Qué es una lista?¶

    Una lista es una colección ordenada de elementos. Se utiliza para almacenar productos, contactos, canciones, tareas o mensajes. Cada elemento ocupa una posición, denominada índice, que comienza en 0.

    En Kotlin distinguimos:

    Tipo Creación habitual ¿Permite modificar sus elementos mediante esa referencia?
    List<T> listOf(...) No; interfaz de solo lectura
    MutableList<T> mutableListOf(...) Sí; añadir, modificar y eliminar

    Solo lectura no significa inmutable

    List impide modificar la colección mediante esa interfaz, pero no garantiza que el objeto subyacente sea inmutable. Tampoco impide modificar el estado interno de objetos almacenados en ella.

    1.1. Crear listas¶

    fun main() {
    val edades: List<Int> = listOf(18, 21, 19)
    val nombres = listOf("Ana", "Luis", "Marta") // Tipo inferido
    val productos = mutableListOf("Ratón", "Teclado")
    val vacia = mutableListOf<String>()

    println(edades)       // [18, 21, 19]
    println(nombres.size) // 3
    println(productos)    // [Ratón, Teclado]
    println(vacia.isEmpty()) // true
}

    El parámetro genérico <Int> o <String> especifica el tipo de los elementos. Una lista vacía necesita un tipo explícito o un contexto que permita inferirlo.

    1.2. Diferencia entre val y var¶

    val alumnos = mutableListOf("Ana", "Luis")
alumnos.add("Eva") // Correcto: se modifica la colección
// alumnos = mutableListOf("Pedro") // Error: val impide reasignar

var ciudades = listOf("Valencia", "Alicante")
ciudades = listOf("Castellón") // Correcto: se reasigna la referencia
// ciudades.add("Elche") // Error: List no dispone de add()

    Idea clave

    val impide reasignar la variable; MutableList determina si puedes modificar los elementos de la colección.

    2. Acceder a los elementos¶

    Para una lista listOf("Ana", "Luis", "Eva") los índices son 0, 1 y 2.

    fun main() {
    val nombres = listOf("Ana", "Luis", "Eva")

    println(nombres[0])              // Ana
    println(nombres.first())         // Ana
    println(nombres.last())          // Eva
    println(nombres.lastIndex)       // 2
    println(nombres.getOrNull(10))   // null
    println("Luis" in nombres)       // true
    println(nombres.indexOf("Eva"))  // 2
}
    Operación Significado
    lista.size Número de elementos
    lista[index] Elemento de la posición indicada
    lista.first() / last() Primer o último elemento
    lista.firstOrNull() Primer elemento o null si está vacía
    lista.getOrNull(i) Elemento o null si el índice no existe
    lista.contains(x) / x in lista Comprueba si existe un valor
    lista.isEmpty() / isNotEmpty() Comprueba si está vacía o no

    Índices fuera de rango

    lista[10] provoca IndexOutOfBoundsException si el índice no existe. first() y last() también fallan sobre listas vacías. Para estos casos usa getOrNull(), firstOrNull() y lastOrNull().

    3. Modificar listas mutables¶

    3.1. Añadir, actualizar y eliminar¶

    fun main() {
    val frutas = mutableListOf("Manzana", "Pera")

    frutas.add("Plátano")                // Añade al final
    frutas.add(1, "Naranja")             // Inserta en índice 1
    frutas.addAll(listOf("Kiwi", "Uva")) // Añade varios
    frutas[0] = "Fresa"                 // Sustituye un elemento
    frutas.remove("Pera")               // Elimina por valor
    frutas.removeAt(0)                  // Elimina por índice

    println(frutas) // [Naranja, Plátano, Kiwi, Uva]
    println("Elementos: ${frutas.size}")
    frutas.clear()                      // Vacía la lista
    println(frutas.isEmpty())           // true
}
    Método Resultado o comportamiento
    add(valor) Añade un elemento; devuelve Boolean
    add(indice, valor) Inserta en una posición
    addAll(otraLista) Añade una colección
    remove(valor) Elimina la primera coincidencia; devuelve Boolean
    removeAt(indice) Elimina por posición y devuelve el elemento eliminado
    clear() Elimina todos los elementos
    lista[indice] = valor Sustituye un elemento

    3.2. Ejemplo práctico: carrito de compra¶

    fun main() {
    val carrito = mutableListOf("Monitor", "Ratón")
    carrito.add("Teclado")
    carrito.remove("Ratón")

    println("Carrito de compra:")
    carrito.forEachIndexed { indice, producto ->
        println("${indice + 1}. $producto")
    }
    println("Total de artículos: ${carrito.size}")
}

    Salida esperada:

    Carrito de compra:
1. Monitor
2. Teclado
Total de artículos: 2

    4. Recorrer listas con bucles¶

    4.1. Bucle for¶

    fun main() {
    val nombres = listOf("Ana", "Luis", "Marta")
    for (nombre in nombres) {
        println("$nombre tiene ${nombre.length} caracteres")
    }
}

    4.2. Recorrer índices y elementos¶

    fun main() {
    val notas = listOf(7, 9, 5)

    for (i in notas.indices) {
        println("Nota ${i + 1}: ${notas[i]}")
    }

    notas.forEach { nota -> println("Calificación: $nota") }

    notas.forEachIndexed { indice, nota ->
        println("Posición $indice: $nota")
    }
}

    4.3. Bucle while¶

    fun main() {
    val invitadosPorFamilia = listOf(2, 4, 1, 3)
    var indice = 0
    var total = 0

    while (indice < invitadosPorFamilia.size) {
        total += invitadosPorFamilia[indice]
        indice++
    }
    println("Invitados totales: $total") // 10
}

    ¿Qué recorrido utilizar?

    Utiliza for (elemento in lista) cuando no necesites índices, forEachIndexed cuando necesites ambos y while cuando quieras controlar manualmente la posición.

    5. Operaciones habituales sobre listas¶

    Las siguientes operaciones producen resultados nuevos sin modificar la lista original (excepto las variantes sort(), reverse() y otras operaciones específicas de colecciones mutables).

    fun main() {
    val numeros = listOf(8, 3, 10, 2, 5)

    println(numeros.sorted())               // [2, 3, 5, 8, 10]
    println(numeros.sortedDescending())     // [10, 8, 5, 3, 2]
    println(numeros.reversed())             // [5, 2, 10, 3, 8]
    println(numeros.filter { it >= 5 })    // [8, 10, 5]
    println(numeros.map { it * 2 })        // [16, 6, 20, 4, 10]
    println(numeros.sum())                 // 28
    println(numeros.average())             // 5.6
    println(numeros.maxOrNull())           // 10
    println(numeros.any { it > 9 })        // true
    println(numeros.all { it > 0 })        // true
    println(numeros.count { it % 2 == 0 }) // 3
}
    Función Utilidad
    filter { condición } Seleccionar elementos
    map { transformación } Transformar elementos
    sorted() Orden ascendente
    sortedBy { propiedad } Ordenar objetos por una propiedad
    find { condición } Primera coincidencia o null
    any { condición } ¿Alguno cumple la condición?
    all { condición } ¿Todos cumplen la condición?
    count { condición } Contar coincidencias
    sumOf { expresión } Sumar valores calculados

    5.1. Ejemplo práctico: aprobados y nota media¶

    fun main() {
    val notas = listOf(4.5, 7.0, 8.5, 3.0, 6.0)
    val aprobados = notas.filter { it >= 5.0 }

    println("Aprobados: $aprobados")
    println("Número de aprobados: ${aprobados.size}")
    println("Media: ${notas.average()}")
    println("Nota máxima: ${notas.maxOrNull()}")
}

    6. Listas de objetos y data class¶

    En aplicaciones reales, las listas suelen contener objetos en lugar de cadenas o números aislados.

    data class Producto(
    val id: Int,
    val nombre: String,
    val precio: Double,
    val stock: Int
)

fun main() {
    val productos = listOf(
        Producto(1, "Teclado", 35.50, 8),
        Producto(2, "Monitor", 189.99, 3),
        Producto(3, "Ratón", 19.95, 0)
    )

    val disponibles = productos.filter { it.stock > 0 }
    val ordenados = productos.sortedBy { it.precio }
    val valorInventario = productos.sumOf { it.precio * it.stock }

    disponibles.forEach { println("${it.nombre}: ${it.precio} €") }
    println("Ordenados: ${ordenados.map { it.nombre }}")
    println("Valor del inventario: $valorInventario €")
}

    data class proporciona automáticamente operaciones útiles como toString(), equals(), hashCode() y copy() a partir de las propiedades del constructor principal.

    6.1. Actualizar un objeto de una lista¶

    val productos = mutableListOf(
    Producto(1, "Teclado", 35.50, 8),
    Producto(2, "Monitor", 189.99, 3)
)

val indice = productos.indexOfFirst { it.id == 2 }
if (indice != -1) {
    productos[indice] = productos[indice].copy(stock = 5)
}
println(productos)

    Por qué usar copy()

    En modelos con propiedades val, copy() permite crear una versión actualizada del objeto sin modificar el original. Esta técnica facilita la gestión predecible del estado de la interfaz.

    7. Listas en Android con Jetpack Compose¶

    En Compose, una colección que cambia y debe actualizar la interfaz necesita un estado observable. Modificar una MutableList ordinaria almacenada con remember no garantiza que Compose detecte esos cambios. Para este ejemplo utilizamos mutableStateListOf().

    7.1. Mostrar una lista con LazyColumn¶

    LazyColumn muestra una lista vertical y compone los elementos según se necesitan, por lo que es adecuada para colecciones que pueden crecer.

    @Composable
fun ListaAlumnos() {
    val alumnos = listOf("Ana", "Luis", "Marta", "Eva")

    LazyColumn {
        items(alumnos) { alumno ->
            Text(
                text = alumno,
                modifier = Modifier.padding(12.dp)
            )
        }
    }
}

    Imports principales: androidx.compose.foundation.lazy.LazyColumn, androidx.compose.foundation.lazy.items, androidx.compose.material3.Text, androidx.compose.foundation.layout.padding, androidx.compose.ui.Modifier y androidx.compose.ui.unit.dp.

    7.2. Aplicación completa: añadir y eliminar productos¶

    Crea un proyecto Empty Activity con Kotlin y Jetpack Compose. Sustituye el contenido de MainActivity.kt por el siguiente código, adaptando el nombre del paquete a tu proyecto. El ejemplo utiliza las dependencias de Compose Material 3 de la plantilla.

    package com.example.listaproductos

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            MaterialTheme {
                Surface(modifier = Modifier.fillMaxSize()) {
                    GestorProductos()
                }
            }
        }
    }
}

data class ProductoLista(val id: Int, val nombre: String)

@Composable
fun GestorProductos() {
    var nombre by rememberSaveable { mutableStateOf("") }
    var siguienteId by rememberSaveable { mutableIntStateOf(1) }
    val productos = remember { mutableStateListOf<ProductoLista>() }

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        Text("Gestión de productos", style = MaterialTheme.typography.headlineSmall)

        OutlinedTextField(
            value = nombre,
            onValueChange = { nombre = it },
            label = { Text("Nombre del producto") },
            modifier = Modifier.fillMaxWidth(),
            singleLine = true
        )

        Button(
            onClick = {
                val texto = nombre.trim()
                if (texto.isNotEmpty()) {
                    productos.add(ProductoLista(siguienteId++, texto))
                    nombre = ""
                }
            },
            enabled = nombre.isNotBlank()
        ) {
            Text("Añadir producto")
        }

        Text("Productos registrados: ${productos.size}")

        LazyColumn(
            modifier = Modifier.weight(1f),
            verticalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            items(productos, key = { it.id }) { producto ->
                Card(modifier = Modifier.fillMaxWidth()) {
                    Row(
                        modifier = Modifier
                            .fillMaxWidth()
                            .padding(12.dp),
                        horizontalArrangement = Arrangement.SpaceBetween
                    ) {
                        Text(
                            text = producto.nombre,
                            modifier = Modifier.weight(1f)
                        )
                        TextButton(onClick = { productos.remove(producto) }) {
                            Text("Eliminar")
                        }
                    }
                }
            }
        }
    }
}

    Comportamiento: el usuario escribe un nombre, pulsa «Añadir producto» y aparece una tarjeta. Al pulsar «Eliminar», la tarjeta desaparece y se actualiza el contador.

    Persistencia del estado

    En este ejemplo rememberSaveable conserva el texto y el identificador siguiente cuando Android puede guardar y restaurar el estado; la lista de productos solo usa remember, por lo que no se conserva tras recrear la Activity por un giro de pantalla ni tras recrear el proceso. Para conservar la lista, utiliza un Saver apropiado, un ViewModel con estado guardado o persistencia según los requisitos de la aplicación.

    7.3. ¿Cómo se produce la recomposición?¶

    1. El usuario pulsa «Añadir producto».
    2. Se ejecuta productos.add(...) sobre una lista observable.
    3. Compose detecta el cambio de estado.
    4. Las partes de la interfaz que leen ese estado pueden recomponerse: el contador y los elementos de LazyColumn.

    No debe confundirse recomposición con recreación completa de la Activity.

    8. Errores frecuentes¶

    Error Causa Solución
    IndexOutOfBoundsException Índice inexistente Comprobar límites o usar getOrNull()
    NoSuchElementException first() o last() sobre lista vacía Usar firstOrNull() / lastOrNull()
    Unresolved reference: add Intentar modificar List Utilizar MutableList
    No se actualiza Compose Cambios en una lista no observable Utilizar mutableStateListOf o estado inmutable observable
    Desaparecen elementos al girar Estado almacenado solo con remember Guardar/restaurar el estado de forma adecuada
