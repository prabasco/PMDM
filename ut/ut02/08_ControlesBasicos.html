    Controles básicos de Android con Jetpack Compose¶

    En el apartado anterior hemos estudiado los elementos de una interfaz de usuario. Ahora veremos los controles básicos y cómo utilizarlos con Kotlin y Jetpack Compose, el sistema moderno de creación de interfaces declarativas de Android.

    En las interfaces tradicionales se utilizan vistas como TextView, EditText, CheckBox, RadioButton, Button, ToggleButton, ImageButton e ImageView, normalmente definidas mediante XML. En Jetpack Compose se emplean funciones @Composable que describen la interfaz a partir de su estado.

    • Ejemplo de proyecto usando Jetpack Compose (ProductosApp)

    Importante

    Los ejemplos siguientes están escritos para Jetpack Compose con Material 3, no para interfaces XML. Las funciones setText(), getText() o findViewById() pertenecen al enfoque tradicional basado en vistas y no son necesarias para los ejemplos de Compose.

    Preparación de los ejemplos¶

    Crea en Android Studio un proyecto Empty Activity con Kotlin y Jetpack Compose. Los ejemplos pueden incorporarse a la función setContent de MainActivity:

    setContent {
    MaterialTheme {
        MiPantalla()
    }
}

    Cada ejemplo define su propia función MiPantalla() o una función de demostración. Prueba los ejemplos por separado, o cambia el nombre de la función cuando combines varios en un proyecto.

    Los componentes Material 3 suelen importarse desde androidx.compose.material3, mientras que remember, mutableStateOf y getValue/setValue pertenecen a androidx.compose.runtime. Android Studio permite añadir los imports automáticamente con Alt + Enter.

    TextView → Text¶

    En Android tradicional, TextView muestra texto que el usuario no puede editar. En Compose se utiliza Text().

    Los parámetros principales son:

    • text: texto que se muestra.
    • color: color del texto.
    • fontSize: tamaño en sp.
    • fontWeight: grosor, por ejemplo FontWeight.Bold.
    • fontStyle: estilo, por ejemplo FontStyle.Italic.
    • modifier: permite configurar tamaño, fondo, márgenes internos y otros aspectos.
    @Composable
fun EjemploText() {
    Text(
        text = "Bienvenidos a Android",
        color = Color(0xFF1565C0),
        fontSize = 22.sp,
        fontWeight = FontWeight.Bold,
        modifier = Modifier
            .background(Color(0xFFE3F2FD))
            .padding(12.dp)
    )
}

    En Compose, para cambiar el texto se actualiza el estado del que depende Text, en lugar de llamar a setText().

    EditText → TextField y OutlinedTextField¶

    EditText es una caja editable para introducir datos. En Compose sus equivalentes más habituales son TextField() y OutlinedTextField() (con borde).

    Parámetros principales:

    • value: texto actual.
    • onValueChange: función que recibe el texto nuevo.
    • label: etiqueta del campo.
    • placeholder: pista visible cuando el campo está vacío.
    • singleLine: limita la entrada a una línea.
    • keyboardOptions: permite sugerir un tipo de teclado.
    @Composable
fun EjemploTextField() {
    var nombre by remember { mutableStateOf("") }

    Column(modifier = Modifier.padding(16.dp)) {
        OutlinedTextField(
            value = nombre,
            onValueChange = { nombre = it },
            label = { Text("Nombre") },
            placeholder = { Text("Escribe tu nombre") },
            singleLine = true
        )
        Text("Hola, $nombre")
    }
}

    remember conserva el valor durante las recomposiciones y mutableStateOf permite que Compose observe los cambios. Para conservar el texto también ante una recreación de la actividad, como un giro de pantalla, se puede utilizar rememberSaveable en lugar de remember.

    Contraseñas

    Para contraseñas puede utilizarse PasswordVisualTransformation() con el parámetro visualTransformation de OutlinedTextField. Esto oculta visualmente los caracteres, pero no constituye por sí solo un sistema de autenticación seguro.

    CheckBox → Checkbox¶

    CheckBox permite seleccionar o deseleccionar una opción. En Compose se utiliza Checkbox().

    • checked: estado booleano (true o false).
    • onCheckedChange: función que recibe el nuevo estado.
    @Composable
fun EjemploCheckbox() {
    var aceptado by remember { mutableStateOf(false) }

    Row(verticalAlignment = Alignment.CenterVertically) {
        Checkbox(
            checked = aceptado,
            onCheckedChange = { aceptado = it }
        )
        Text("Acepto las condiciones")
    }
}

    El valor de aceptado se puede consultar en cualquier parte de esta función para activar o desactivar otras acciones.

    RadioButton → RadioButton¶

    RadioButton representa una opción dentro de un conjunto de selección exclusiva. En el sistema tradicional se agrupa dentro de RadioGroup. En Compose no hace falta un RadioGroup: se comparte una única variable de estado entre todos los botones.

    • selected: indica si la opción está seleccionada.
    • onClick: acción que cambia la selección.
    @Composable
fun EjemploRadioButton() {
    val opciones = listOf("Java", "Kotlin", "Python")
    var seleccion by remember { mutableStateOf("Kotlin") }

    Column {
        opciones.forEach { opcion ->
            Row(verticalAlignment = Alignment.CenterVertically) {
                RadioButton(
                    selected = seleccion == opcion,
                    onClick = { seleccion = opcion }
                )
                Text(opcion)
            }
        }
        Text("Lenguaje seleccionado: $seleccion")
    }
}

    La exclusividad se consigue porque todos los RadioButton comparan su valor con la misma variable. En una aplicación completa conviene hacer pulsable toda la fila y añadir semántica de accesibilidad al grupo.

    Button → Button¶

    Button permite ejecutar una acción al pulsarlo. En Compose se utiliza Button(onClick = { ... }).

    Otros botones disponibles en Material 3 son OutlinedButton, TextButton, ElevatedButton y FilledTonalButton.

    @Composable
fun EjemploButton() {
    var contador by remember { mutableIntStateOf(0) }

    Column {
        Text("Pulsaciones: $contador")
        Button(onClick = { contador++ }) {
            Text("Pulsar")
        }
    }
}

    Cada pulsación incrementa contador y Compose actualiza el texto automáticamente.

    ToggleButton → Switch¶

    En Android tradicional, ToggleButton permite mantener un estado de encendido o apagado. En Material 3 se utiliza habitualmente Switch(), que resulta apropiado para activar o desactivar una configuración.

    • checked: estado actual.
    • onCheckedChange: función que recibe el nuevo estado.
    @Composable
fun EjemploSwitch() {
    var notificaciones by remember { mutableStateOf(true) }

    Row(verticalAlignment = Alignment.CenterVertically) {
        Text("Notificaciones")
        Switch(
            checked = notificaciones,
            onCheckedChange = { notificaciones = it }
        )
    }
}

    Si se necesita un botón que permanezca seleccionado, Material 3 también ofrece patrones de botones seleccionables; Switch es el equivalente más sencillo para un ajuste binario.

    ImageButton → IconButton¶

    En Android tradicional, ImageButton muestra una imagen pulsable. En Compose se utiliza normalmente IconButton() con un Icon() en su interior.

    @Composable
fun EjemploIconButton() {
    var favorito by remember { mutableStateOf(false) }

    IconButton(onClick = { favorito = !favorito }) {
        Icon(
            imageVector = if (favorito) Icons.Filled.Favorite
                          else Icons.Filled.FavoriteBorder,
            contentDescription = if (favorito) "Quitar de favoritos"
                                 else "Añadir a favoritos"
        )
    }
}

    Este ejemplo utiliza los iconos Favorite y FavoriteBorder de androidx.compose.material.icons.filled. Puede ser necesario añadir la dependencia androidx.compose.material:material-icons-extended al módulo para disponer de ellos.

    contentDescription facilita que los lectores de pantalla describan la acción del botón.

    ImageView → Image¶

    ImageView muestra imágenes. En Compose se utiliza Image(), normalmente con painterResource() para cargar recursos de res/drawable.

    • painter: recurso gráfico que se muestra.
    • contentDescription: descripción accesible de la imagen (puede ser null si es decorativa).
    • modifier: tamaño y disposición.
    • contentScale: determina cómo se ajusta la imagen al espacio disponible.

    Primero añade una imagen llamada paisaje.png a la carpeta app/src/main/res/drawable.

    @Composable
fun EjemploImage() {
    Image(
        painter = painterResource(id = R.drawable.paisaje),
        contentDescription = "Paisaje de montaña",
        modifier = Modifier
            .fillMaxWidth()
            .height(180.dp),
        contentScale = ContentScale.Crop
    )
}

    ContentScale.Crop rellena el espacio disponible y puede recortar partes de la imagen. ContentScale.Fit muestra la imagen completa manteniendo sus proporciones.

    Para imágenes descargadas de Internet se suelen utilizar bibliotecas como Coil, que permiten cargar imágenes mediante AsyncImage. painterResource() está destinado a recursos locales de la aplicación.

    Organización de los componentes¶

    En Compose, los componentes se colocan dentro de contenedores de diseño:

    Contenedor Función
    Column Organiza los elementos verticalmente.
    Row Organiza los elementos horizontalmente.
    Box Permite superponer o alinear elementos dentro de un mismo espacio.
    LazyColumn Muestra listas verticales de forma eficiente.

    El objeto Modifier permite personalizar cada componente. Algunas funciones habituales son padding(16.dp), fillMaxWidth(), size(48.dp), background(...) y clickable { ... }.

    Unidades

    • dp: unidad independiente de la densidad de pantalla; se utiliza para dimensiones y espacios.
    • sp: unidad escalable para texto; tiene en cuenta las preferencias de tamaño de fuente del usuario.

    Ejemplo completo: formulario de alumno¶

    El siguiente ejemplo combina texto, entrada de datos, casilla, selección exclusiva, interruptor y botón. Puede utilizarse como contenido de setContent { MaterialTheme { FormularioAlumno() } }.

    @Composable
fun FormularioAlumno() {
    var nombre by rememberSaveable { mutableStateOf("") }
    var lenguaje by rememberSaveable { mutableStateOf("Kotlin") }
    var acepta by rememberSaveable { mutableStateOf(false) }
    var avisos by rememberSaveable { mutableStateOf(true) }
    var resultado by rememberSaveable { mutableStateOf("") }

    Column(
        modifier = Modifier
            .fillMaxSize()
            .verticalScroll(rememberScrollState())
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        Text("Registro del alumno", fontSize = 24.sp)

        OutlinedTextField(
            value = nombre,
            onValueChange = { nombre = it },
            label = { Text("Nombre del alumno") },
            modifier = Modifier.fillMaxWidth(),
            singleLine = true
        )

        Text("Lenguaje preferido")
        listOf("Java", "Kotlin").forEach { opcion ->
            Row(verticalAlignment = Alignment.CenterVertically) {
                RadioButton(
                    selected = lenguaje == opcion,
                    onClick = { lenguaje = opcion }
                )
                Text(opcion)
            }
        }

        Row(verticalAlignment = Alignment.CenterVertically) {
            Checkbox(
                checked = acepta,
                onCheckedChange = { acepta = it }
            )
            Text("Acepto las condiciones")
        }

        Row(verticalAlignment = Alignment.CenterVertically) {
            Text("Recibir avisos")
            Spacer(modifier = Modifier.width(12.dp))
            Switch(
                checked = avisos,
                onCheckedChange = { avisos = it }
            )
        }

        Button(
            enabled = nombre.isNotBlank() && acepta,
            onClick = {
                resultado = "Alumno: $nombre | Lenguaje: $lenguaje | " +
                    "Avisos: ${if (avisos) "Sí" else "No"}"
            }
        ) {
            Text("Registrar")
        }

        Text(resultado)
    }
}

    En este ejemplo:

    1. rememberSaveable conserva los valores básicos ante recreaciones habituales de la actividad.
    2. Cada control recibe su valor actual y una función que lo actualiza.
    3. El botón solo está habilitado cuando se ha escrito un nombre y se han aceptado las condiciones.
    4. Al pulsar Registrar, el resultado aparece en pantalla sin acceder directamente a ningún componente mediante identificadores.

    Comparación entre Android tradicional y Jetpack Compose¶

    Android con XML (Views) Jetpack Compose Uso principal
    TextView Text Mostrar texto
    EditText TextField / OutlinedTextField Introducir texto
    CheckBox Checkbox Selección independiente
    RadioButton + RadioGroup RadioButton + estado compartido Selección exclusiva
    Button Button Ejecutar acciones
    ToggleButton Switch Activar o desactivar opciones
    ImageButton IconButton + Icon Acción mediante icono
    ImageView Image Mostrar imágenes
    LinearLayout vertical Column Distribución vertical
    LinearLayout horizontal Row Distribución horizontal

    Conceptos fundamentales¶

    • @Composable identifica una función que describe parte de la interfaz.
    • Estado: dato que determina lo que aparece en pantalla, por ejemplo el texto de un campo o si una casilla está marcada.
    • Recomposición: Compose vuelve a ejecutar las funciones necesarias cuando cambian los estados que utilizan.
    • remember: conserva un valor entre recomposiciones, pero no garantiza conservarlo ante la recreación de la actividad.
    • rememberSaveable: conserva estados compatibles con el mecanismo de guardado de Android en recreaciones habituales.
    • Elevación del estado (state hoisting): consiste en mover el estado a un componente superior y pasar a los componentes hijos el valor y las funciones de actualización.

    La idea principal de Compose es describir cómo debe verse la interfaz para un estado determinado. Cuando el estado cambia, Compose se encarga de actualizar las partes necesarias de la pantalla.

    • PR 209 (RA2 / CE2b / IC2 / 5p) Diseña una pequeña interfaz con dos textos jerarquizados utilizando un Column. Aplica márgenes, colores y tamaños diferentes para comprender cómo Compose organiza y alinea los elementos en la pantalla.

    • PR 210 (RA2 / CE2b / IC2 / 5p) Crea una función @Composable con un botón que, al pulsarse, muestre un mensaje en consola. Este ejercicio busca reforzar la relación entre la interfaz declarativa y la lógica de interacción del usuario a través del evento onClick.

    • PR 211 (RA2 / CE2c / IC3 / 5p) Implementa un contador de pulsaciones utilizando un estado mutable con remember. Cada vez que el usuario presione el botón, el valor deberá incrementarse y mostrarse en pantalla, evidenciando la recomposición automática de Compose.

    • PR 212 (RA2 / CE2c CE2d / IC3 / 5p) Diseña una interfaz que permita al usuario escribir su nombre en un TextField y muestre en tiempo real un saludo personalizado. Observa cómo el estado del texto se actualiza dinámicamente conforme cambia la entrada del usuario.

    • AP 214 (RA2 / CE2c CE2d / IC3 / 3p) Diseña una miniapp con un campo de texto (TextField) y dos botones que permitan al usuario escribir un mensaje y, opcionalmente, borrarlo o reiniciar el contenido. Implementa el manejo de estado con remember y mutableStateOf para comprender cómo se actualiza la interfaz al modificar el estado interno.
